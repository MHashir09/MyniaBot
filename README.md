# MyniaBot
A simple discord bot. Made for the purpose of being able to post anonymous confessions or vent in a dedicated channel. (Work in progress)

# Key improvements
- Now you can upvote and downvote confessions
- Comment on confessions and encourage discussion
- Improved security from abusers and error handling

# Future Goals
- Improve vent.js as well
- Improve utility commands
- Improve box UI/UX
- Add blacklist command for trolls
- Improve moderation and user experience

# Setup details
- Change config.json as per your need
- Use `npm i` and  then `npm run dev`
- Make sure to give proper permissions to the bot and enable guild members intent from Discord developer portal
